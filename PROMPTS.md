# AI Prompts Used

## Initial Project Setup
**Prompt:** "Now, you are a web development, please help me to create an Anime Search App. The requirements are: React 18+ with TypeScript, Redux for state management, react-router-dom for navigation, debounced search with 250ms delay, server-side pagination for search page, must run on port 4000 with npm only."

**Context:** Used for overall project planning and architecture decisions.

## Component Structure
**Prompt:** "Create a minimal but complete React TypeScript component structure for an anime search app with search bar, anime cards, pagination, and detail page components."

**Context:** Used for creating the component hierarchy and basic structure.

## Redux Implementation
**Prompt:** "Implement Redux Toolkit slices for anime search with async thunks, including search state management, pagination, and anime details fetching."

**Context:** Used for state management implementation with proper TypeScript typing.

## API Integration
**Prompt:** "Create API service functions for Jikan anime API with proper TypeScript interfaces and error handling."

**Context:** Used for API service layer and type definitions.

## Debounced Search
**Prompt:** "Implement a custom React hook for debouncing search input with 250ms delay and integrate it with Redux search functionality."

**Context:** Used for creating the debounce hook and search optimization.

## Styling and UX
**Prompt:** "Add minimal inline CSS styling for a clean, responsive anime search interface with hover effects and proper loading states."

**Context:** Used for basic styling and user experience improvements.
